# Лабораторная работа № 3 — MILP-модель дискретного выбора

Вариант 6: **«Выбор проектов при капитальном бюджете с зависимостями
(0/1 рюкзак+)»** — 15 проектов, 5 зависимостей, ИТ-платформа с фиксированными
затратами (big-M связка).

Студент: Осипов В. А., группа Б24-517. Seed данных: **10116**.

## Установка

```bash
cd lab3
uv venv .venv
uv pip install -r requirements.txt
```

Требуется Python 3.11+ (проверялось на 3.15). Версии библиотек зафиксированы в
`requirements.txt`: numpy 2.5.5, scipy 1.18.1 (солвер HiGHS 1.12.0 внутри),
matplotlib 3.11.2.

## Запуск

Одна команда прогоняет весь конвейер (данные → модель → решение → независимая
проверка → эксперименты 1–6 и доп. задание → CSV/PNG/логи):

```bash
.venv/bin/python main.py
```

(или `python main.py` в активированном окружении)

Один и тот же seed даёт одни и те же данные (`data_gen.py`, seed=10116), поэтому
результат полностью воспроизводим.

## Структура репозитория

| Файл | Назначение |
| --- | --- |
| `main.py` | конвейер одной командой |
| `data_gen.py` | детерминированная генерация (seed 10116) и загрузка (`load()`) данных варианта → `data/` |
| `model.py` | построение матриц MILP/LP (формулировки `agg`/`disagg`, константа big-M) |
| `solve.py` | решение: `scipy.optimize.milp` (MILP) и `linprog(method='highs')` (LP), перехват лога HiGHS |
| `verify.py` | независимая проверка решения на чистом NumPy (без объекта солвера) |
| `experiments.py` | эксперименты 1–6 + доп. задание |
| `plots.py` | PNG-графики (backend Agg) |
| `data/` | данные варианта: `projects.csv`, `meta.json`, `GENERATION.md` (процедура генерации) |
| `build_pdf.py` | сборка REPORT.md в PDF: `.venv/bin/python build_pdf.py` → `ЛР3_Осипов_ВА_Б24-517.pdf` |
| `output/` | артефакты: `solution.csv`, `scenarios.csv`, `exp_*.csv`, `verification.txt`, `*.png`, `solver_*.log` |
| `REPORT.md` | отчёт по требованиям задания |

## Пример вывода

```
[MILP] статус: optimal; цель = 877.5000 млн руб.; двойственная граница = 877.5000; узлов ветвления = 0
[LP  ] цель = 901.1696 млн руб.; дробные переменные: x3=0.518; интегральный зазор = 2.70%
НЕЗАВИСИМАЯ ПРОВЕРКА ... ИТОГ: ПРОЙДЕНА
[перебор] полный перебор 2^16 комбинаций: оптимум 877.5000 млн руб., оптимумов 1, совпадает с MILP: True
```

Конвейер генерирует данные по seed 10116 в `data/` (идемпотентно) и далее
читает вариант из `data/projects.csv` + `data/meta.json` (`data_gen.load()`):
правка файлов данных реально влияет на решение, модель отделена от данных.

Полный отчёт — в `REPORT.md`.
